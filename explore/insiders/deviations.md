## Phase 2 price rebuild rule — recorded before any corporate-action reconciliation run

The 2026-09-23 price-rebuild request supersedes the earlier use of EODHD `adjusted_close` for this diagnostic. These rules apply uniformly to every valid training-sample ticker and every candidate event, independent of observed returns. The sealed filing-date holdout remains rejected before reading a price or action cache.

- Fetch each symbol's full historical `splits/{SYMBOL}` and `div/{SYMBOL}` JSON feeds once and cache each response with a UTC retrieval time. Treat SEC ticker strings that cannot be a single EODHD symbol as unresolved; never guess a replacement. A missing, failed, or malformed action response is **not** equivalent to an empty action history and blocks the symbol's return calculation.
- Use only raw EODHD `open`, `close`, and `volume` plus official split and dividend records. A split ratio `new/old` on ex-date t gives share multiplier `S_t`; use the JSON `unadjustedValue` dividend in USD, `D_t`, per post-action share. For a position held overnight, daily total return is `S_t × (raw_close_t + D_t) / raw_close_(t−1) − 1`. On the entry date, buy at the raw open after any ex-date action and use raw close/raw open minus one; no pre-entry action entitlement. At an open mark on later held days, use `S_t × (raw_open_t + D_t) / raw_close_(t−1)` times the prior total-return level. Refuse an action with an invalid ratio, missing unadjusted amount, non-USD currency, or date ambiguity instead of substituting an adjusted price.
- Reconciliation rule: for each symbol-day with raw close-to-close return **strictly beyond ±75%** and **no split or dividend record within ±3 observed symbol sessions**, mark it suspected. Mark it a defect if volume on that day is zero, or if any of the next five observed symbol-session raw closes reverses at least 50% of the original dollar price move toward the pre-move close. A day with a corporate-action record in the ±3-session band is exempt from this defect rule, but its action is still used in total-return arithmetic. Do not add any other outlier threshold or inspect a trade outcome to decide a defect.
- Exclude every candidate event whose observed symbol-session window from 20 sessions before entry through 60 sessions after entry contains a defect; if the symbol terminates early, inspect through its final close. Record excluded counts by filing year and dollar-volume bucket. Other previously declared identity, transaction-price, cost, portfolio, and early terminal-exit rules remain unchanged. An interior missing session is an unresolved price path, not an inferred delisting.

The [EODHD corporate-actions documentation](https://eodhd.com/financial-apis/api-splits-dividends) defines the split `date` and `split` ratio and the dividend ex-`date`, `unadjustedValue`, and `currency` fields. Both endpoints are per symbol and require an API token for this universe. The symbol catalog's absence of a delisting-reason field remains unresolved; unknown terminal histories retain the previously requested −30% assumption, without claiming a merger exception.

## Phase 2 offline price rebuild — superseding direction, locked before run

The user replaced the corporate-action download with an offline reconstruction after the prior rule was recorded. The EODHD credential was unavailable; **no full-universe corporate-action run occurred**. A public AAPL demo endpoint smoke check was made under the prior direction. The draft fetch/official-action code and its demo cache were removed because they no longer implement the requested method. This section is the operative rule for the offline run; it was written before applying it to training returns.

For each locally available EODHD symbol with a training-sample SEC event, compute raw close-to-close return `r_raw,t = close_t / close_(t−1) − 1`, adjustment factor `f_t = adjusted_close_t / close_t`, and factor step `q_t = f_t / f_(t−1)`. The first bar has no classifiable return. Apply the following mutually exclusive order to every later symbol-day, independent of portfolio outcome:

1. **Split.** `|r_raw,t| > 25%` and `q_t` is within 2% relative to `1/(1+r_raw,t)`; specifically `|q_t / [1/(1+r_raw,t)] − 1| ≤ 2%`. Set total return to `(1+r_raw,t)q_t − 1`, the split-neutral return.
2. **Dividend.** Otherwise, `0.1% ≤ |q_t−1| ≤ 10%` and `|r_raw,t| < 25%`. Implied dividend yield is `(1+r_raw,t)(q_t−1)`; total return is raw return plus that yield. A negative factor step produces a negative implied yield under this symmetric reading of “changes.”
3. **Adjustment error.** Otherwise, `|q_t−1| > 25%` and `|r_raw,t| < 5%`. Ignore the factor step and use raw return.
4. **Suspected defect.** Otherwise, `|r_raw,t| > 75%` and no matching split step from rule 1. Mark the day an actual defect only when its volume is zero or any of the next five observed symbol-session raw closes reverses at least half the original dollar price move toward the pre-move close. If the suspected move lacks those confirmations, use its raw return and leave it in the sample. No outcome-based exception is permitted.
5. **Ordinary raw day.** All remaining days use raw return. Invalid or missing close, adjusted close, factor, or volume is recorded as unprocessable rather than silently substituted.

For a position entered at the next raw open, use raw close/raw open on its entry day. After entry, compound only the classified daily total returns; no EODHD adjusted-close return enters the position path. The 20-session pre-entry Corwin–Schultz spread and the existing 5 bp each-way commission remain. A candidate whose observed symbol-session `[−20,+60]` window relative to entry contains an actual defect is excluded regardless of return. For a terminal symbol the window ends at its final available close and the unknown-reason −30% terminal return remains; an interior price gap is unresolved, not a delisting. Counts by bucket and filing year will count unique `(bucket, filing year, symbol, symbol-day)` occurrences in candidate windows, so overlapping events do not multiply a class count. Malformed SEC ticker strings are not guessed into symbols.

Independent validation is a fixed seeded 300-event, post-2016, bucket-stratified sample: 100 executed primary clusters from each of the three buckets, sampled without replacement using NumPy `default_rng(20260923)` over `(ticker, filing_date)`-sorted rows. Alpaca credentials may be read from environment variables only and used solely on the market-data host. If absent, inspect existing Tiingo audit files for sampled-symbol coverage; otherwise report validation unavailable. No new strategy filters, thresholds, or windows are authorized.

Implementation note after the first offline run: invalid or zero raw closes produced NumPy divide warnings while already being classified as `unusable`. Division was changed to masked division for those rows; the result for every valid symbol-day is unchanged. The run produced local per-symbol classified series, a candidate-window class census, an exclusion register, primary portfolio/factor tables, a terminal-history audit, and an ORM/MCEP daily spot-check under `explore/insiders/`. No new selection rule was added. Alpaca credentials were absent from the environment; the seeded sample had no overlap with the existing Tiingo cross-check symbol files, so the independent price comparison was unavailable.

Post-run limitation, without rule change: AAPL's 2020-08-31 raw return is −74.152% and its factor step is almost 4×. The implied split-neutral return is +3.391%, which exceeds the fixed ±2% match tolerance. It remains an `ordinary_raw` day at −74.152% because it also falls short of the >75% suspected-defect threshold. The rule thus fails to neutralize at least one visible split pattern. No corrective threshold or exception was tried; all reported results keep the locked rule and are labelled unreliable.

## Phase 2 robustness screen — recorded before this run, 2026-09-24

The prior offline raw-price/factor rebuild is **superseded** as a return source. In the fixed 300-event validation sample, it labelled BW's 2019-07-24 1-for-10 reverse split `suspected_defect` rather than `split`, producing a +749.47-percentage-point event-return discrepancy from Tiingo. EODHD's adjusted-close event return was within 0.02 point of Tiingo for BW and had at least as good aggregate agreement in every dollar-volume bucket of the sample. This is a source-choice correction, not evidence about the insider effect. The return source for the new training-sample run is each symbol's local EODHD adjusted close, scaled to the raw entry open as in the first-return precommit. The Tiingo raw EOD response cache and request timestamps were deleted to comply with the free-tier no-persistent-cache term; only derived validation tables/report remain.

The following **two robustness screens** are fixed before running them. They are not replacements for the original primary specification and introduce no new event, liquidity, date, or price-quality filter. All three variants use the same code-P, two-insider 30-day cluster starts and 90-day cooldown, the pre-entry-only coverage screen, EODHD adjusted-close paths, a 60-session target exit, the existing −30% unknown-reason terminal haircut for delisted symbols, the same 20-session Corwin–Schultz full-spread charge on each side plus 5 bp commission each way, and official monthly FF5 + momentum + short-term reversal factors with Newey–West lag 3. Filings in the sealed holdout are refused before any price or factor read.

1. **Pooled event-return winsorization.** Compute each executed primary cluster's gross entry-open-to-exit-close return, including the terminal haircut but **before** spread and commission. Across all three dollar-volume buckets, calculate the empirical 1st and 99th percentiles with NumPy's default linear interpolation. Clip each gross event return at those two common cutoffs. Preserve all interim adjusted-price marks and the original entry/exit dates; implement the cap only in the exit-day value so each event's full-window gross return equals the clipped value. Entry and exit costs remain unchanged. This is an ex-post robustness diagnostic, not a prospective trade rule; pooled training outcomes determine its bounds.
2. **Monthly median of active-position returns.** For each calendar month, compute one gross and one net within-month return for every position active on at least one session. A new entrant starts at its entry-day adjusted open; a carry-in position starts at the preceding month's final adjusted close. The month ends at its last held adjusted close, with the terminal haircut where applicable. Net return applies the existing entry charge if entry occurs that month and the existing exit charge if exit occurs that month, multiplicatively. Take the median of these position returns as that month's gross/net portfolio statistic, with no cash or scheduled reweighting leg. Compare that monthly statistic to the same-month IWM return and factors. Partial-month positions remain partial-month contributions, so this median screen is not an executable portfolio simulation.

The original variant retains the existing equal-weight calendar-time simulator. Report for all three variants, separately by the three fixed dollar-volume buckets: executed cluster count, mean gross and net monthly excess over IWM, FF5+momentum+reversal monthly alpha and HAC t-statistic, residual standard deviation, and worst net month. The event pool and factor files are unchanged across variants. No return or factor model outside these three variants is added in this run.
